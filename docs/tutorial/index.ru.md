# Туториал: бот поддержки

В этом туториале вы собираете один пайплайн с нуля и наращиваете его шаг за
шагом. Это бот поддержки: он берёт тикет, разбирается, о чём тот, ищет ответ в
базе знаний и либо отвечает, либо отдаёт тикет человеку.

Каждый тип узла появляется один раз — там, где он действительно нужен. К концу
граф выглядит так:

![Готовый бот в редакторе](../img/tut-final.png)

## Что понадобится

Для шагов с 1 по 6 хватит ядра:

```bash
pip install stageflow-framework
```

Скриншоты сняты в [редакторе
StageFlow](https://github.com/leo-need-more-coffee/stageflow-ui) — это
веб-страница, которая рисует и отлаживает граф. Сама она ничего не исполняет:
она обращается к бэкенду, где лежат ваши стадии. Чтобы повторять за
туториалом в редакторе, запустите
[бэкенд примера](https://github.com/leo-need-more-coffee/stageflow-example):

```bash
git clone https://github.com/leo-need-more-coffee/stageflow-example
cd stageflow-example
pip install -r requirements.txt
python main.py                 # http://127.0.0.1:8765
```

и рядом сам редактор:

```bash
git clone https://github.com/leo-need-more-coffee/stageflow-ui
cd stageflow-ui
npm start                      # http://127.0.0.1:8080
```

Откройте `http://127.0.0.1:8080`, введите адрес бэкенда на экране подключения
и загружайте пайплайн нужного шага через «File» → «Import JSON…».

Готовый бот, его стадии и файлы с данными лежат в репозитории примера. Здесь
мы собираем то же самое, по одной идее за раз.
