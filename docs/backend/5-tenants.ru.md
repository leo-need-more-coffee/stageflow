# 5. Кто звонит

`Policy` — это объект. Превратить в него HTTP-запрос и есть последний шаг, и
именно о нём у StageFlow намеренно нет мнения.

**Авторизации во фреймворке нет и не будет.** Ядро принимает политику;
токены, заголовки, сессии, тенанты и подписки — вещи, на которые у каждой
платформы уже есть свой ответ, и ответ фреймворка был бы ещё одной вещью, с
которой приходится бороться. В примере всё это — сорок строк в
`app/auth.py`, и настоящий бэкенд заменяет этот файл, не трогая больше
ничего.

## Тарифы — это таблица

```python
PLANS: dict[str, Policy] = {
    "full":  Policy(),                     # неограниченный пример
    "basic": Policy(stages=RULES_ONLY | PLUMBING, node_types={...}, limits=...),
    "pro":   Policy(node_types=None, limits=Limits(counters={"tokens": 200_000, ...})),
}
```

Настоящая платформа находит тенанта и собирает политику из его подписки.
Слова «тариф», «basic» и «pro» — дело платформы, как и прайс-лист,
превращающий `result.meters` в счёт.

Одно из примера стоит скопировать в любом случае: **`basic` умеет что-то
запускать**. У него есть свой пайплайн, `06-rules-only.json`, — весь бот без
единой модели. Тариф, который не может запустить вообще ничего, — не дешёвый
тариф, а сломанный, и пользователя он учит только тому, что продукт не
работает.

## Решают учётные данные

```python
AUTH_HEADER = os.environ.get("SF_AUTH_HEADER", "Authorization")
TOKENS = _parse_tokens(os.environ.get("SF_TOKENS", ""))   # "tok:plan,tok:plan"


def caller_plan(request: Request) -> str:
    if not TOKENS:                       # ничего не настроено: никого не различаем
        return OPEN_PLAN
    token = credential(request)
    if token is None:
        raise HTTPException(401, f"no credentials: send a token in the '{AUTH_HEADER}' header")
    plan = TOKENS.get(token)
    if plan is None:
        raise HTTPException(401, "the credentials were not recognised")
    return plan
```

**Имя** заголовка настраивается, потому что бэкенды расходятся во мнениях —
`Authorization: Bearer …`, `X-Api-Key: …`, что там положил шлюз, — и
редактору тут решать нечего. Если не настроено ничего, авторизации нет вовсе,
и пример запускается и работает, в чём и смысл примера.

Со стороны редактора это поле, и его значение проверяется тем же запросом,
которым проверяется адрес, — так что неверный токен неверен на том экране,
где его правят, а не на первом прогоне:

![Экран подключения отказывает, поле учётных данных развёрнуто](../img/be-auth.png)

## Быть показанным тариф — не значит быть на нём

Вот часть, которую важно не испортить, потому что очевидный на вид срез
уничтожает всё, что построили два предыдущих шага.

Читающие эндпоинты принимают `?plan=` — **без проверки, от кого угодно**:

```python
@router.get("/meta")
async def meta(caller: CallerPlan, plan: ShownPlan = None) -> dict:
    shown = plan or caller
    policy = policy_for(shown)
    return {"api": 1, "plan": shown, "plan_source": source_of(plan),
            "plans": plan_names(), **capabilities(policy), "limits": _limits_of(policy)}
```

Имя — не разрешение. Рисовать не значит запускать, а редактор, которому надо
авторизоваться, прежде чем погасить элемент палитры, — это редактор, который
никто не настраивает; поэтому «как этот граф выглядел бы на тарифе подешевле»
может спросить кто угодно. `plans` — список, который можно предложить, чтобы
клиенту не пришлось зашивать имена, которых он знать не может.

Прогон такого параметра не принимает:

```python
@router.post("/run", status_code=201)
async def start_run(body: RunRequest, caller: CallerPlan) -> dict:
    if body.plan is not None and body.plan != caller:
        raise HTTPException(403, f"this graph was prepared for plan '{body.plan}', "
                                 f"and these credentials are on '{caller}'")
    run = runs.start(body.model_dump(), policy_for(caller))
```

`body.plan` едет в обратную сторону: это то, **подо что рисовали**, а не
просьба на этом запуститься. Сказать это — значит дать назвать расхождение, а
это ответ куда лучше, чем груда ошибок валидации про отдельные стадии:

![Отказ, называющий оба тарифа](../img/be-run-refused.png)

Прокиньте `?plan=` в запуск вместо этого — одна строка, и очень очевидная на
вид — и каждый потолок из двух предыдущих шагов станет query-параметром.
`check_pipelines.py` в примере проверяет, что этого никто не сделал: такое
свойство ломается незаметно для любого теста эндпоинтов.

## Что из этого делает редактор

Всё это собрано в один диалог — «File» → «Connection…» или клик по строке
бэкенда в статус-баре:

![Диалог подключения](../img/be-connection.png){ width="520" }

Адрес (его смена перезагружает страницу: это почва, на которой стоит сессия),
учётные данные (применяются на месте — токен протухает *во время* работы, а
отвергнутый откатывается, чтобы сессия выжила), тариф, под который рисуем, и
то, что ответил бэкенд. `?plan=basic` в собственном URL редактора открывает
его сразу так, а статус-бар помечает превью как превью, чтобы его нельзя было
принять за разрешение.

## Где проходит граница

| | Фреймворк | Платформа |
|---|---|---|
| что может содержать граф | `Policy` | какая именно политика |
| сколько прогон может потратить | `Limits`, счётчики, `BudgetExceeded` | сколько стоит единица |
| кто вызывающий | — | целиком |
| месячная квота, очередь, пул | — | целиком |

Последняя строка важна не меньше остальных. `concurrency: 8` ограничивает
**один прогон**; сто прогонов — это восемьсот задач, а сколько прогонов
существует, ядро знать не может. Допуск — очередь, пул на тенанта, месячный
бюджет — дело платформы, а дело ядра — держать потолок одного прогона и
честно сообщать, во что он обошёлся.
